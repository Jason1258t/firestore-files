## Контекст

`firestore-files` хранит файлы в Cloud Firestore кусками, без Firebase Storage и тарифа Blaze. Пакет выделен из сайта «TFC Планы» (`/Users/ivan/vscodeProjects/tfc-taskmanager`, там же `src/lib/files.ts` — исходная реализация).

Что уже готово и проверено:
- ядро (`src/store.ts`): загрузка, чтение, подписка, удаление, SHA-256, отмена, `cleanupIncomplete`, `mine()`;
- конфиг (`src/config.ts`) с проверкой подстановок `$file` / `$owner` / `$new`;
- генератор правил и CLI (`src/rules.ts`, `bin/cli.mjs`);
- React-хуки (`src/react.ts`);
- 6 модульных и 14 сквозных тестов на эмуляторе Firestore — все зелёные;
- README — пользовательская документация, держать актуальной.

Сайт потом переведут на этот пакет, поэтому **формат данных менять нельзя**: поля метаданных `name`, `size`, `type`, `chunks`, `complete`, `createdAt` (число, мс) и необязательные `uid`, `sha256`; кусок `{ i, data: Bytes }` в подколлекции. Любое изменение формата — только с явного согласия пользователя.

## Шаг 1. Перенести файлы

Скопировать всё, кроме сгенерированного:

```bash
rsync -a --exclude node_modules --exclude dist --exclude '*.log' \
  /Users/ivan/vscodeProjects/tfc-taskmanager/packages/firestore-files/ ./
```

Исходную папку **не удалять** — её уберут при переводе сайта на пакет.

Проверить, что всё работает на новом месте:

```bash
npm ci
npx tsc --noEmit
npm test               # 6 модульных
npm run test:emulator  # 14 сквозных; нужны firebase CLI (установлен глобально) и Java (есть)
npm pack --dry-run     # в архиве: dist/*, bin/cli.mjs, README.md, package.json
```

Если что-то упало — сначала починить, потом двигаться дальше.

## Шаг 4. Что стоит доделать в коде до 1.0

Делать по согласованию, не всё сразу:

- **Сообщения ошибок.** Сейчас на русском; для публичного пакета — английский по умолчанию. Код ошибки (`FileStoreError.code`) уже есть — по нему можно локализовать на стороне приложения.
- **Сборка.** `tsc` без бандлера даёт ESM. CJS не нужен: firebase v10+ сам ESM-first. Проверить импорт из Vite-проекта и из Node.
- **Тест на `firebase@10`.** В CI отдельная матрица или хотя бы проверка типов.
- **README: раздел «Миграция с самописного хранения»** — как подключить пакет к существующим данным того же формата (старые файлы без `sha256` читаются без проверки суммы, выключать `checksum` не нужно).
